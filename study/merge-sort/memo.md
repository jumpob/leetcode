- ただ再帰に対して誤解してて、マージのところがいまいち腑に落ちてなかった

```
mergeSortHelper() {
  mergeSortHelper(); //
  mergeSortHelper();

  // 上2つが終わって、全体通して1回しか呼ばれないものと勘違いしてた
  // 実際は再帰だから、↑の(1),(2)（のさらに再帰で呼ばれるものも含む）でもmergeは呼ばれる
  merge();
```

- mergeの引数としてほしいのは、もとの配列に加え、左と右をわけるための情報
- なので以下
  - left: 左配列の左端
  - mid: 左配列の右端 かつ 右配列左端(+1が必要)
  - right: 右配列の右端
